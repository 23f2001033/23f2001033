### 👋 About Me

I'm a final-year **BS in Data Science and Applications** student at **IIT Madras**, building AI agents, evaluation systems, and applied ML — mostly at hackathons, sometimes for coursework, always end-to-end. I care more about whether a system's output is *actually correct* than whether it *sounds* correct — verification layers, audit trails, honest abstention, and distribution diagnosis show up across almost everything below.

### 🚀 Featured Projects

<details>
<summary><b>Suraksha Copilot</b> — KSP Datathon 2026 (Karnataka State Police × Hack2skill)</summary>
<br>
Role-aware, bilingual crime-intelligence copilot over a 1,100+ station police database — a 3-tier text-to-SQL engine (verified templates → generative SQL with execution-consensus → honest abstention), row-level RBAC per rank, and a hash-chained audit log so every answer traces back to the query that produced it.
<br><br>
🔗 <a href="https://github.com/23f2001033/ksp-datathon-2026-suraksha-copilot">Repository</a>
</details>

<details>
<summary><b>ChainSentinel</b> — Kaya AI IIT India Hackathon 2026, Supply Chain track</summary>
<br>
Forecasts construction material delays with a zero-shot time-series foundation model (Amazon Chronos-2), then an agent pulls the exact contract clause, runs what-ifs through a real critical-path optimizer, and drafts an alert for human approval. Working end-to-end demo, not just a pitch deck.
<br><br>
🔗 <a href="https://github.com/23f2001033/ChainSentinel">Repository</a>
</details>

<details>
<summary><b>Vishwas — MSME Credit Passport</b> — IDBI Innovate 2026, Team Perceptron</summary>
<br>
A portable, explainable financial-health score for MSMEs built from GST/UPI/Account-Aggregator data, owned by the business itself rather than locked inside one bank's system — live client-side demo with a transparent weighted-scorecard engine.
<br><br>
🔗 <a href="https://github.com/23f2001033/vishwas-msme-credit-passport">Repository</a>
</details>

<details>
<summary><b>Rally</b> — Slack Agent Builder Challenge</summary>
<br>
A Slack agent that fills volunteer shifts by skill and availability, auto-rescues cancellations, and turns logged hours into grant-ready impact reports — exposed over an MCP server so the same roster is queryable from Claude Desktop.
<br><br>
🔗 <a href="https://github.com/23f2001033/Rally">Repository</a>
</details>

<details>
<summary><b>Autonomous Research Agent</b> — self-directed</summary>

Multi-agent RAG system (LangGraph) that turns a question into a cited report, with a dedicated verification stage that checks every claim against its source using natural-language inference — flagging unsupported claims instead of trusting the model at face value.
<br><br>
🔗 <a href="https://github.com/23f2001033/Autonomous-Research-Agent">Repository</a>
</details>

<details>
<summary><b>AssetFlow</b> — hackathon build, live on Vercel</summary>

Enterprise asset & resource management platform (Next.js/TypeScript/PostgreSQL) with real product-management artifacts underneath it — competitor analysis, five user personas, prioritized user stories, and explicit scope cuts, not just a CRUD app.

🔗 <a href="https://github.com/23f2001033/odoo-2026">Repository</a>
</details>

<details>
<summary><b>Semantic Cache for LLM Inference</b> — self-directed</summary>
<br>
Embedding-based caching layer (FAISS + FastAPI) that matches semantically equivalent LLM queries, evaluated against a deliberately adversarial test set — 91.2% precision, with the acceptance threshold set around the failure mode that actually mattered.
<br><br>
🔗 <a href="https://github.com/23f2001033/Semantic-Cache-for-LLM">Repository</a>
</details>

<details>
<summary><b>Music Genre Classification</b> — IIT Madras Deep Learning coursework</summary>
<br>
Fine-tuned EfficientNet-B2 on a 5.3GB, 10-class real-world audio dataset (Macro F1 0.803, rank #595 nationally on Kaggle). Diagnosed the real bottleneck as a train-test distribution mismatch and built a synthetic data pipeline to fix it, rather than only tuning the architecture.
